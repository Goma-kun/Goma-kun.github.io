NISHIRA

現場の困りごとを、AIを使って動くツールにしています。

コールセンター／ヘルプデスクの現場で10年以上働くなかで見つけた「手作業で消えている時間」を、Chrome拡張機能・Google Apps Script・デスクトップアプリとして形にしてきました。

プログラミングは専門ではありません。要件定義から実装・デバッグ・Chrome ウェブストアの審査通過までを、生成AIとの対話で一人で完遂しています。公開中の拡張機能は3本です。

まもるくん

AI音声書き起こし・ログ作成ツール ／ Chrome拡張・Web・iPhone対応

話した内容をその場で文字にして、生成AIが読める日本語に整えます。通話しながらのログ作成や、議事録・アイデアの書き留めに使えます。Chrome拡張のほか、iPhoneのSafariからも同じものが使えます。

  • リアルタイム音声認識＋Gemini API による「清書」（話し言葉を読める文章に整形）
  • 音声認識は11言語対応。表示は日本語のまま、聞き取る言語だけ切り替えられます
  • 画面が消えても録音が止まらないよう、iOS Safari 固有の挙動に個別対応（23分連続動作を確認）
  • 清書プロンプトへの指示混入（プロンプトインジェクション）対策を実装

SmartShot

要素を狙って撮れるスクリーンショット拡張

マニュアルや手順書を作るときの「きれいに撮り直す」手間をなくすための拡張機能です。撮りたい部分にカーソルを合わせると、その要素の枠に自動で吸い付きます。撮った画像はそのままクリップボードに入ります。

  • ページ上の全要素の辺を収集し、ドラッグ・リサイズ時に8pxで吸着（エッジスナップ）
  • 要素の border-radius を読み取り、角丸をそのまま切り抜き
  • 選択中にスクロールしても、選択を保ったまま撮り直して継続
  • 撮影と同時にクリップボードへコピー（貼り付けるだけで使える）

おさむくん

定型文の検索・コピー ／ 完全オフライン動作

よく使う文章を登録しておいて、検索してすぐコピーできる拡張機能です。ブラウザのサイドパネルに常駐するので、メール画面を開いたまま横で探せます。コールセンターや事務職で、定型文をスプレッドシートで管理している現場を想定しました。

  • スプレッドシートの3列（カテゴリ／概要／本文）を選んで貼り付けるだけで一括登録。CSV・TSVファイルの読み込みにも対応
  • 保存・追加・削除・インポートは、直前のひとつを取り消せる
  • 要求する権限は sidePanel と storage の2つだけ。ページの読み取り権限は求めず、外部通信のコードを一行も含まない設計
  • キーボードだけで完結（↑↓で選択、Enterでコピー、Escでクリア）

In-house

業務内製ツール（Google Apps Script）

就業先の業務環境で開発・運用しているものです。情報セキュリティ規定に則り、ここでは課題と解決方針のみ記載しています。

ヘルプデスク業務自動化システム

課題
共有アカウントを複数名に委任して運用していたところ、同時操作が不正アクセスとして検知されアカウントロックが発生し、業務が止まっていた
解決
インストール可能なトリガーを応用し、「操作」は個人アカウント・「実行」は共有アカウントの権限で行う構成に。共有アカウントへの同時ログイン自体を不要にした
成果
ロックのリスクを根本から排除しつつ、対外的には代表アカウントとして振る舞う自動化フローを確立

データ連携転記支援ツール（サイドバーUI）

課題
管理画面やDBからの手動転記によるミスと工数
解決
スプレッドシート上に HTML Service で独自の入力サイドバーを開発。TSV等の非構造データを解析し、自動抽出・整形して展開
成果
転記ミスをゼロに。非同期通信によるリアルタイムのステータス表示でUXを改善

対応履歴作成・テンプレート自動生成ツール

課題
オペレーターのスキル差によるログ品質のばらつきと記入漏れ
解決
問い合わせ種別に応じて確認項目テンプレートを動的に生成。ユーザー情報を解析し定型フォーマットへマッピング
成果
必須項目をシステム側から提示して属人化を解消。管理用プレフィックスの自動付与で検索性・集計効率が向上

カレンダー連携型 日程調整支援ツール

課題
アカウントの管理権限が他部署にあり、API連携に必要な認証情報が得られない環境で、日程調整メールの作成と空き確認を手作業で行っていた
解決
「送信権限がない」という制約を前提に、メール文面の下書き生成とカレンダーの仮押さえまでを自動化する半自動フローを構築
成果
組織のセキュリティポリシーと権限の壁を越えずに、手作業の工程を大きく削減

Desktop

ヘルプデスク業務支援・AI議事録アシスタント

個人PCで開発した Python デスクトップアプリ（Windows／Mac対応）。

通話の可視化と解決策提示をワンストップで

目的
コールセンター業務における保留時間の短縮とログ作成負荷の軽減
構成
Python / CustomTkinter（UI）/ threading（非同期処理）、Google Cloud Speech-to-Text、Gemini API
機能
リアルタイム文字起こし、エラー画面のスクリーンショットをAIが解析して解決策を提示、通話後に「要約・対応内容・Next Action」を指定フォーマットで自動生成
設計
個人情報保護の観点から、取得するのはオペレーター自身の音声のみ。入力ソースを物理的に分離し、顧客の音声が外部AIへ送られない構成にしている

Approach

開発の進め方について

ここに挙げたツールは、私がプログラミング言語を学んで書いたものではありません。現場で困っていることをAIに説明し、対話しながら要件を固め、実装とデバッグを進めています。

ただ、動くところまで持っていくのは「AIに頼めば済む」という話ではありませんでした。Chrome ウェブストアの審査には単一目的の説明と権限の正当化が要りますし、iOS Safari が画面消灯時に返す非標準エラーも、CSVのBOMの扱いも、実機で踏んで一つずつ潰しています。仕様を決め、詰まった箇所を切り分け、直ったことを確かめる——その判断の部分は自分でやっています。

ノンプログラマーでも、現場を知っていればここまで作れる。その実証として見ていただければ幸いです。
