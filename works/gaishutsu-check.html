外出前チェック

遠隔開発の準備がそろっているかを1画面で（Mac 用）

デモ（20秒）：起動すると準備をまとめてチェック。足りないもの（スリープ防止など）は、その場のボタンで直せます。

全部そろうと「外出して大丈夫です」。ブラウザを開いたままリロードすれば、その場で調べ直します。

なりたち
外出先から iPhone で自宅の Claude Code に指示を出せるようにしています（Claude Code の公式機能です）。ただ、つながる状態を保つには「Mac がスリープしない設定が生きているか」「遠隔操作の機能が有効か」など、そろっていないといけない条件がいくつもあり、ひとつでも欠けると外出先からは直せません
目的
出かける前の確認があちこちに散らばっていて、ひとつ確認し忘れたせいで外出先からつながらない、を防ぐことです
使い方
アプリをダブルクリックすると、必要な条件をまとめて調べて、結果を1画面に並べます。その場で直せる問題（スリープ防止が止まっている、など）は、直すかどうかをその場で聞いてきます
使ったもの
AppleScript、シェルスクリプト
作った理由
業務内製の日程調整ツールと同じ考え方です。あちこち見て回っていた確認を、ひとつの画面に集約すると、確認そのものが数秒で終わり、見落としもなくなります。自分の開発環境に対しても、業務と同じ型でツールを作っています
